How this test works:

Every "spin" performs a fresh crypto.getRandomValues() call. The test does not animate the wheel because that would waste time; it tests the actual random-selection algorithm directly.

If all weights are empty or zero, every entry has equal probability. If weights are supplied, the expected probability is based on those weights.

With truly random results, the actual percentages will not be exactly equal to the expected percentages. Small differences are normal.
